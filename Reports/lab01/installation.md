# Installation of logisim-evolution

## OS Information
- Name: Arch Linux
- Architecture: x64
- Linux Version: 7.1.4
- Package Manager: pacman

## Using Arch User Repository
Package `logisim-evolution` can be downloaded from AUR. However, the version of the package is outdated, hence deprecated.

## From Github Releases
Logisim-evolution is an open-source digital logic design and simulation software used for designing, testing, and analyzing digital circuits. It provides an intuitive graphical interface for creating combinational and sequential logic circuits and is widely used in digital electronics and computer architecture courses. The latest stable release is Version 4.1.0.

### 1. Downloading and Installing Logisim-evolution
Open the release page: [Link](https://github.com/logisim-evolution/logisim-evolution/releases)

### 2. Download the appropriate installer for your operating system from the latest release.
-  Linux (Universal): `.jar` file

```
java -jar logisim-evolution-4.1.0-all.jar
```
